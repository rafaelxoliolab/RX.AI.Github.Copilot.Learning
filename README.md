## What is Github Copilot?
GitHub Copilot is an AI coding assistant that helps you write code faster and with less effort.

See more details [Github Docs](https://docs.github.com/en/copilot/get-started/what-is-github-copilot)

### AI tools
- ChatGPT - https://chatgpt.com/

- OpenAi Codex - Helps to translate to different languages

### Large Language Models (LLMs)
LLMs are artifical intelligence models designed and trained to understand, generate, and manipulate human language.


### Diagram tools

#### PUML

PlantUML is a highly versatile tool that facilitates the rapid and straightforward creation of a wide array of diagrams.

For more reference see [PlantUML](https://plantuml.com/).

**GitHub Copilot & PUML**

You can generate the Puml files for yout diagrams using Github copilot and then load them in the [PUML Online Server](https://www.plantuml.com/plantuml/uml/SyfFKj2rKt3CoKnELR1Io4ZDoSa70000)
